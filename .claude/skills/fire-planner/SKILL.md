# FIRE planner (India)

1. Read the "Finance & FIRE" section of the private profile. If the FIRE plan is still TODO, ask the user
   to paste the summary from earlier chats or a 1% Club export before giving numbers.
2. Core math (show working, INR, lakh/crore):
   - FIRE corpus = annual expenses at FIRE date × multiple (default 30–33×, i.e. ~3–3.3% SWR for India's
     higher inflation; explain the choice).
   - Inflate today's expenses at 6–7% (education 10%+) to the target year.
   - Required SIP = solve future-value with step-up (default 10%/yr); show base/optimistic/pessimistic returns.
   - Separate goal buckets: emergency fund, kids' education, house, retirement corpus.
3. Instruments: EPF/VPF, PPF, NPS (80CCD(1B)), equity index/flexi-cap MFs, debt/liquid funds, gold/SGB,
   term + health insurance. Note current-year tax rules only after checking with WebSearch.
4. Monthly check-in: net worth delta, savings rate, SIP adherence, allocation drift (rebalance if >5%),
   progress % to corpus. Offer a Google Sheet tracker in the Life OS folder if none exists.
5. Never store account numbers, PAN or balances in this repo. Not SEBI-registered advice — say so for
   product-specific recommendations.
